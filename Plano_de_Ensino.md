# Plano de Ensino -- Frameworks Front-end

## Descrição

A disciplina tem como objetivo desenvolver aplicações web responsivas
para ambientes industriais utilizando tecnologias e frameworks
Front-end.

## Objetivo

-   Programar aplicações responsivas para a internet.

## Capacidades Técnicas

-   Configurar ambiente de desenvolvimento.
-   Aplicar tecnologias Front-end.
-   Desenvolver código seguindo boas práticas.
-   Escolher frameworks adequados.
-   Criar aplicações responsivas com foco em UX.

## Capacidades Socioemocionais

-   Ética profissional.
-   Pensamento crítico e inovação.
-   Resolução de problemas complexos.
